# Лабораторные работы по веб-технологиям

Сайт компании «Food Construct» — доставка бизнес-ланчей в Москве.
В репозитории лежат все 10 лабораторных работ, каждая в своей папке.

## Структура

```
.
├── index.html        — список лабораторных
├── lab1 … lab10      — лабораторные работы
│   ├── css/
│   ├── images/       — картинки этой лабораторной
│   ├── js/
│   └── *.html
├── Dockerfile
├── docker-compose.yml
├── nginx.conf
└── package.json
```

| Папка | Что реализовано |
|-------|-----------------|
| `lab1`  | Главная страница: семантика HTML, Google-шрифт, стили CSS, таблица, футер |
| `lab2`  | Страница «Собрать ланч», CSS Grid и Flexbox, адаптивность |
| `lab3`  | Форма заказа, отправка на `httpbin.org` |
| `lab4`  | Вывод блюд на JavaScript, выбор блюда, подсчёт стоимости |
| `lab5`  | Категории блюд и фильтры |
| `lab6`  | Блок комбо, проверка заказа, уведомления |
| `lab7`  | Загрузка блюд через API |
| `lab8`  | `localStorage`, страница `checkout.html`, отправка заказа |
| `lab9`  | История заказов: просмотр, редактирование, удаление |
| `lab10` | Лендинг на Bootstrap 5 (`index.html`), домашняя страница — `about.html` |

## Запуск

```bash
docker compose up -d --build
```

Сайт: <http://localhost:8080>

Без Docker:

```bash
python -m http.server 8080
```

## API

Лабораторные 7–10 работают с сервером `https://amd.dedyn.io:15243`.
Ключ задаётся в `lab8/js/api.js` (он же используется в `lab9` и `lab10`):

```js
const API_KEY = 'd3792683-e66e-4d04-867a-4905fa35dbf5';
```

Сервер принимает любой ключ-UUID, заказы хранятся отдельно для каждого ключа.
По умолчанию указан рабочий ключ — заказы сразу уходят на сервер.
Если очистить ключ, включится демо-режим с сохранением заказов в `localStorage`.

Блюда при недоступности сервера берутся из `lab7/data/dishes.json` (таймаут 4 с),
поэтому сайт продолжает работать и без API.
